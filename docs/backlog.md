# BelZakupki — Бэклог и Идеи по Развитию (Feature Backlog)

В данном документе собраны предложения, архитектурные улучшения и новые функции для развития проекта мониторинга госзакупок в Беларуси.

---

## 1. Новые источники тендеров (Scraping Backlog)
Для охвата всего рынка закупок необходимо интегрировать следующие порталы:
- [x] **ГИАС (gias.by)** — Государственная информационно-аналитическая система управления государственными закупками. Содержит агрегированные данные.
- [x] **БУТБ (butb.by / zakupki.butb.by)** — Белорусская универсальная товарная биржа. Важнейший источник коммерческих и биржевых торгов.
- [ ] **Улучшения IceTrade (icetrade.by)** — Оптимизация стабильности парсинга, обход ограничений на количество запросов.

---

## 2. Глубокий сбор метаданных тендера (Deep Scraping)
На данный момент сборщик считывает информацию только из общей таблицы результатов поиска. Необходимо реализовать переход на саму страницу тендера (`/tenders/view/{id}`) для сбора детальной информации:
- [x] **Контакты заказчика** — сбор имени ответственного лица, номера телефона и e-mail.
- [x] **Условия и сроки поставки / оплаты** — извлечение регионов поставки, требований по отсрочке платежа и авансированию.
- [x] **Многолотовые закупки (Lots)** — корректный парсинг каждого лота отдельно (сейчас они объединяются под общим тендером), так как у каждого лота может быть свой бюджет и технические требования.

---

## 3. Надежность сбора документов и вложений
- [x] **Поддержка архивов (.zip, .rar, .7z)** — автоматическая распаковка скачанных архивов вложений и извлечение текстов из всех вложенных ТЗ.
- [x] **Поддержка бинарных/устаревших форматов (.doc, .xls)** — использование специализированных библиотек или утилит конвертации для чтения файлов спецификаций, подготовленных в старых версиях MS Office.
- [x] **OCR (Оптическое распознавание символов)** — интеграция Tesseract OCR или внешнего API для извлечения текста из сканированных PDF-документов и изображений (часто ТЗ сканируют в виде картинок).
- [x] **Оптимизация скачивания** — обработка ошибок сети при скачивании крупных файлов (>10-20 МБ) с поддержкой докачки и лимитами на размер файлов.

---

## 4. Сбор и анализ информации о результатах (Winner Intelligence)
Важнейшее коммерческое преимущество — аналитика прошедших тендеров для оценки конкурентов и ценообразования.
- [x] **Парсинг протоколов выбора победителя** — сбор статуса "Закупка завершена / отменена / не состоялась".
- [x] **Извлечение данных о победителе**:
  - Название компании-победителя (УНП, наименование).
  - Итоговая сумма договора (победившее предложение).
  - Скидка от начальной цены (разница между начальной стоимостью и ценой победителя).
- [x] **Список участников** — сбор информации обо всех подавших заявки компаниях для составления карты конкурентов.

---

## 5. Панель аналитики в Dashboard (Business Intelligence)
- [ ] **Раздел "Анализ конкурентов"** — отображение топ-победителей в выбранных нишах, средний процент снижения цены, популярные заказчики.
- [ ] **Раздел "Мои тендеры"** — канбан-доска или реестр со статусами проработки тендеров (в работе, отправлено КП, победа, проигрыш).
- [ ] **Генератор отчетов** — экспорт сводной таблицы релевантных тендеров за неделю/месяц в Excel или PDF для руководства.
